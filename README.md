# Simple Interest Calculator

## Project Description
This project is a simple interest calculator implemented using a Bash script. It calculates simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest (in percentage)
- Time period (in years)

## Output
The calculator displays the simple interest calculated using the provided inputs.

## Technologies Used
- Bash scripting
- Linux command line

## How to Run
1. Clone the repository.
2. Open a terminal in the project directory.
3. Make the script executable:
   `chmod +x simple-interest.sh`
4. Run the script:
   `./simple-interest.sh`

## Example
Principal: 1000  
Rate of Interest: 5%  
Time Period: 2 years  

Simple Interest = (1000 × 5 × 2) / 100 = 100
